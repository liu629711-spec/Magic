技能解剖结构

每个技能均由必需的 SKILL.md 规范文件和可选的随附资源组成： 

skill-name/
├── SKILL.md (必需文件)
│   ├── YAML 头部元数据 (必需)
│   │   ├── name: 技能名称 (必需)
│   │   └── description: 技能描述 (必需)
│   └── Markdown 指令指南 (必需)
├── agents/ 代理配置 (推荐)
│   └── openai.yaml - 技能清单与 UI 徽章元数据
└── 捆绑资源目录 (可选)
    ├── scripts/         - 可执行脚本代码
    │   (Python/Bash/Node)
    ├── references/      - 按需加载至上下文的参考文档
    └── assets/          - 输出产物所需资产（模板、
        图标、模型等）
description SKILL.md 规范说明 严格模式
头部元数据 (YAML)：必须包含 name 和 description。用于指导 Codex 在自主规划时何时自动调起该技能。
指令指南 (Markdown)：清晰的过程化指南。明确脚本执行流程、所需环境变量及前置安全校验点。
确定性工具绑定：存放于 scripts/ 目录下的任何可执行脚本，均会在大模型运行时上下文中映射为带强类型的工具调用。
