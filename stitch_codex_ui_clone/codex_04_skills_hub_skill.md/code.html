Anatomy of a Skill

Every skill consists of a required SKILL.md file and optional bundled resources: 

skill-name/
├── SKILL.md (required)
│   ├── YAML frontmatter metadata (required)
│   │   ├── name: (required)
│   │   └── description: (required)
│   └── Markdown instructions (required)
├── agents/ (recommended)
│   └── openai.yaml - UI metadata for skill lists and chips
└── Bundled Resources (optional)
    ├── scripts/         - Executable code
    │   (Python/Bash/Node)
    ├── references/      - Documentation intended to be
    │   loaded into context as needed
    └── assets/          - Files used in output (templates,
        icons, mockups, etc.)
description SKILL.md Spec Overview Strict Mode
Frontmatter (YAML): Required name and description. Determines when Codex automatically invokes the skill during autonomous operations.
Instructions (Markdown): Clear procedural guide. Outlines how scripts execute, environment variables needed, and safety checkpoints.
Deterministic Tool Bindings: Any executable within scripts/ is mapped as a typed tool call in the LLM runtime context.
