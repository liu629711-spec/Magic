# 历史会议与评审记录

本目录保留产品方向形成过程、技术总监发言、外部评估和专题讨论的原始记录。它们用于追溯依据、分歧和证据边界，不是当前产品规范；需要当前结论时返回 [产品入口](../README.md) 和 [最终产品裁定](../00-项目管理/项目总控.md)。

## 记录分组

| 文件前缀 | 内容 | 使用方式 |
|---|---|---|
| `会议记录-第一轮-*` | 独立事实盘点和初始意见 | 了解当时的证据与分歧 |
| `会议记录-第二轮-*` | 交叉质询和修正 | 追踪观点如何收敛 |
| `会议记录-第三轮-*` | 共同签署和保留阻塞 | 追溯签署条件，不替代验收 |
| `会议记录-U-*` | U-01、U-02、U-05、U-10 等专题讨论 | 只在需要查看专题决策来源时阅读 |
| `产品设计三方对齐会议纪要.md` | 早期产品方向评审 | 仅作历史背景 |

## 维护约束

1. 新的产品结论必须回写正式专题或当前裁定，历史记录只追加，不在此处形成第二个权威版本。
2. 历史记录中的“建议”“待决策”和“有条件一致”不得解释成已通过开发准入。
3. 记录引用路径统一使用本目录路径；移动记录时同步更新引用。
