# PM 工作台

这里是 Magic 项目 PM 的日常入口。只需要先读本目录的四份文档；详细产品原文、专题规则和技术会议记录均为支撑材料。

| 文档 | 用途 | 更新频率 |
|---|---|---|
| [项目总控](项目总控.md) | 当前阶段、目标、里程碑、责任人、风险和本周行动 | 每周 / 状态变化时 |
| [产品基线](产品基线.md) | 产品定位、用户体验、对象边界、首版范围和非目标 | 产品决策变化时 |
| [执行计划与验收](执行计划与验收.md) | 交付路径、准入门槛、验收场景和 Go/No-Go | 计划或证据变化时 |
| [决策风险与问题台账](决策风险与问题台账.md) | 已决策事项、待决策事项、技术核查、风险和责任人 | 每次评审后 |

## 使用规则

1. PM 只在主控文档中维护“当前版本”；支撑材料不再承担当前状态。
2. 新结论先更新主控文档，再把依据链接到支撑材料或会议记录。
3. 没有负责人、截止条件或验收证据的事项，不得标记为完成。
4. 需要展开细节时，沿主控文档链接进入 `90-支撑材料/` 或 `99-历史会议/`。
