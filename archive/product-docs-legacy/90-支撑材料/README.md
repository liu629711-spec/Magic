# 产品支撑材料

本目录保存产品基线的详细展开、专题规则和技术工作台。它们用于查证和实现，不是 PM 日常状态的唯一来源；当前版本以 [PM 工作台](../00-项目管理/README.md) 为准。

## 材料分组

| 类型 | 代表文件 | 用途 |
|---|---|---|
| 方向与说明 | `产品方向总纲.md`、`Magic产品需求文档-白话版.md`、`Magic产品一页纸.md` | 了解历史形成的完整产品叙述 |
| 系统契约 | `Magic最终产品裁定与技术会议输入.md`、`Magic产品系统边界与生命周期底图.md`、`核心对象模型.md` | 追踪对象、责任、状态和当前裁定的详细依据 |
| 模式与工程 | `代理模式.md`、`CEO模式.md`、`工作模式与切换.md`、`工程组织与会话体系.md`、`工程模式蓝图.md` | 设计具体工作方式和长期工程组织 |
| 成员与信息 | `动态Agent会话与成员借调.md`、`任务结果回传与受控信息访问.md` | 设计成员复用、结果回传和信息边界 |
| 治理与资源 | `默认授权与成本治理.md`、`U-10工程工作区文件夹与外部资源讨论稿.md`、`U-11 PM唯一性与交接规则.md`、`U-12权限模式与审批规则.md` | 追踪权限、成本、资源和 PM 治理细节 |
| 证据与会议工作台 | `产品设计基线与新旧产品继承关系.md`、`能力盘点-OpenCode与AgentCore常用能力.md`、`技术会议议题与裁定表.md`、`产品路线图.md` | 证据盘点、技术议题和历史路线参考 |

支撑材料之间存在历史重复是有意保留的，禁止再从支撑材料中复制出新的“当前结论”。需要更新时先更新 PM 工作台，再回写详细章节。
