# 工作模式与切换

## 一、目的

本文定义代理模式、CEO 模式和工程模式之间的用户关系与切换原则。它不规定底层执行引擎如何实现模式，而规定用户看到什么、何时可以切换、切换后什么必须保持连续。

## 二、模式选择模型

模式选择包含两种入口：

### 用户主动选择

用户可以在开始工作前或工作过程中主动进入某种模式。用户如果明确知道自己需要团队协作，可以直接进入 CEO 模式；如果已经在长期建设某个工程，也可以直接进入工程模式。

### 系统提出建议

系统可以从任务规模、持续周期、协作需求和用户表达中识别升级机会，并以不打断当前工作的方式提出建议。

建议不是自动切换，也不是错误提示。用户可以：

- 接受建议并切换
- 忽略建议，继续当前模式
- 关闭或降低此类建议

用户拒绝一次建议，不代表永久拒绝该模式；产品是否记住用户偏好，属于后续记忆设计。

## 三、推荐的切换关系

```text
代理模式
  ├── 用户主动切换到 CEO 模式
  ├── 用户主动进入工程模式
  └── 系统发现复杂协作机会，提出切换建议

CEO 模式
  ├── 继续当前临时团队
  ├── 返回代理模式继续直接执行
  └── 系统发现长期建设特征，建议进入工程模式

工程模式
  ├── 在工程内部直接调用 Agent
  ├── 在工程内部发起 CEO 协作
  └── 暂不定义自动降级或自动解散
```

这里的“返回代理模式”不是删除 CEO 已经完成的工作，而是改变后续任务的执行组织方式。已生成的结果、对话记录和工程状态继续保留。

## 四、自动建议的触发信号

以下信号可以作为建议切换的依据，但不能直接触发模式改变：

### 代理模式建议 CEO 模式

- 用户明确要求多个角度、多人分工或相互审查
- 任务包含多个相对独立且需要并行的方向
- 任务需要辩论、交叉验证或不同专业视角
- 当前工作已经出现大量重复的拆解、汇总和复核
- 用户明确表达“不想自己拆任务”

### CEO 模式建议工程模式

- 用户反复在同一工程中执行长期任务
- 用户开始稳定使用角色、职责或协作关系
- 同一组 Agent 或同一套分工被多次复用
- 工程需要持续积累独立记忆、规范和任务队列
- 用户明确表达“长期建设”“持续维护”“建立团队”等意图

### 不应触发建议的情况

- 仅仅因为一次任务字数很多
- 仅仅因为一次工具调用较多
- 仅仅因为任务失败或耗时较长
- 仅仅因为系统内部进行了任务拆解
- 仅仅因为用户打开了多个文件

## 五、建议的产品形态

建议应当短、可理解、可延后，并且不遮挡当前工作。例如：

> 这项工作包含多个独立方向。要切换到 CEO 模式，让团队分头处理吗？

按钮语义应清楚区分：

- `切换到 CEO 模式`
- `继续当前模式`
- `暂不提示`

工程模式的建议应更谨慎，必须说明它会建立长期工作关系，例如：

> 这项工程可能会持续推进。要建立一个可复用的 Agent 团队吗？

不应使用“升级”“高级模式”“专业模式”等暗示等级的词。

## 六、切换时的连续性要求

切换前，系统应形成当前状态的可继续表达，包括：

- 用户原始目标
- 已完成和未完成的工作
- 已确认的约束
- 已产生的文件和产物
- 当前工作区位置
- 可复用的上下文摘要
- 正在等待的用户决策

切换后，新模式应能从这份状态继续工作，而不是重新从空白开始。

## 七、切换边界

### 代理模式到 CEO 模式

可以在空闲时切换，也可以在执行中提出切换。执行中切换必须明确后续行为：

- 保留已经完成的修改和结果
- 未完成的工作交给 CEO 重新组织
- 不重复执行已经确认完成的任务
- 对无法安全接续的任务先说明，再由用户决定

### CEO 模式到代理模式

可以将后续工作交回单 Agent。已有的临时团队记录保留，但不自动转化为长期团队。

### 任意模式到工程模式

必须经过明确确认。确认内容至少包括：

- 工程名称或识别方式
- 是否创建可复用 Agent
- 初始团队是推荐还是由用户指定
- 哪些上下文进入工程共享空间
- 哪些内容只保留在当前对话

工程模式不能通过一次模糊提示静默创建。

## 八、切换失败和回退

如果切换所需的上下文、权限或执行状态无法安全迁移：

- 当前模式继续保持可用
- 系统说明无法迁移的具体部分
- 不伪造“已切换成功”
- 不删除原有任务或结果
- 允许用户稍后重试或手动开始新模式

## 九、待决策

- 模式切换是对当前对话生效，还是对当前工作区生效
- CEO 模式是否允许在代理模式中以一次指令临时调用，而不改变界面模式
- 工程模式是否可以包含多个 CEO 团队
- 用户是否可以设置默认模式
- “暂不提示”是当前对话级、工作区级还是账户级
