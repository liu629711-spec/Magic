## 阅读规则

1. 新成员：先读 PRD-01，再按工作内容读 PRD-02 至 PRD-05。
2. 技术设计：五份 PRD 是产品输入；架构和前端目录负责技术方案，不重新定义产品语义。
3. 产品变更：先修改对应 PRD，再补充决策记录；不要新建第六份平行 PRD。
4. 旧产品文档、专题和会议记录已移至 `D:\Magic\archive\product-docs-legacy\`，只用于追溯，不作为当前版本。
