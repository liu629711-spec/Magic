# Magic 产品技术声明台账

## 1. 用途

本台账是五份 PRD 的技术事实清洗清单，不是产品 PRD，也不替代用户产品裁定。每一项要么有锁定版本的源码或实验记录，要么明确标记为尚未证实。只有 `S` 项可以作为候选底座事实；`U` 项必须由用户确认是否仍是第一版规则；`H` 项不能据此冻结实现。

| 标记 | 定义 | 当前处理 |
| --- | --- | --- |
| `U` | 产品取舍，源码不能证明 | 第一版范围对齐时由用户确认 |
| `S` | 锁定参考源码直接证明的事实 | 可作为候选能力，但仍需适配设计 |
| `H` | 依赖实际入口、协议或故障语义的技术假设 | 建立可重复实验 |
| `X` | 当前表述与源码不符或过强 | 回写更正，不可进入设计 |

取证版本、已发现问题和详细源码位置见[技术证据审计](技术证据审计-2026-09-02.md)。本台账中的“源码路径”均相对于 `Magic` 根目录；导航文件只用于定位，不作为证据。
