# 06 开发者工具集复刻规格（第一梯队 #6）

> 回答：**AgentCore 开发者工具集每个工具的源码行为是什么、Magic 复刻到什么程度、分几期。**
> 复刻原则：以 AgentCore 源码为行为蓝本（不凭印象），以 DSH/.Magic 插件方式重建（不搬 Python 代码）。
> 蓝本目录：`reference-project/AgentCore/apps/server/agentcore/tools/builtin/`。

## 0. 共通机制（所有工具一致）

| 机制 | AgentCore 事实 | Magic 落点 |
|---|---|---|
| 工作区根 | `normalize_workspace_path` + 越界拒绝（`workspace/_paths`） | `exec.agent.session.header.cwd`（DSH 原生：`packages/fs/tool-fs/src/session-cwd.ts:17-27`），相对路径解析 + `..` 越界拒绝 |
| 工具注册 | `ToolRegistration(surface, audience)` | `ctx.tools.register`（同 magic-ledger/ceo） |
| 审批 | `ToolApproval.NEVER/GRANTABLE/…` | DSH 权限面（ui-approval）按工具类目处理 |
| 产物回执 | `FileProductsContract`（file_product） | 首期省略；产物落工作区由交付物展示自然呈现 |

## 1. `archive_create` / `archive_extract`（蓝本 392 + 300 行）

**AgentCore 行为**：zip 工作区文件/目录到目标 `.zip`；复用 `storage._archive.zip_dir`（VCS/依赖目录剪枝，`max_files`/`max_bytes` 上限 5000 文件 / 200 MiB 原始字节）；extract 有 zip-bomb 顶、zip-slip 拒绝；source/dest 越出工作区明确报错（`archive_create.py:26-28`、`archive_extract.py` zip-slip/越界分支）。

**Magic 复刻（第一期）**：`fflate` 纯 JS zip；同样的 5000/200MiB 顶；zip-slip（条目路径 `..`/绝对路径）拒绝；`archive` 须为工作区内 `.zip`；`dest` 越界拒绝。VCS/依赖剪枝首期做 `.git/`、`node_modules/`。

## 2. `git_ops`（蓝本 2,857 行 / 12 文件）

**AgentCore 行为**（`git_ops/policy.py:17-43,149-157`）：
- 白名单 21 个子命令：status/diff/log/fetch/show/blame/add/commit/branch/checkout/push/pull/init_baseline/clone/stash/merge/rebase/cherry-pick/tag/remote/create_pr；
- 恒写子命令集（add 等）走审批 + ensure_repo；黑名单正则拒绝危险参数（force 系列、registry 覆写类由 package_install 另管）；
- 单进程 20s 超时 + 5s kill slack；diff 输出 16k 截断、status/blame 行数预算；
- 写操作持 repo 锁（`repo_lock.py`）串行。

**Magic 复刻分期**：
- 一期：白名单 + 恒写分类 + 20s 超时 + 输出截断 + 危险参数拒绝（`--force`、`reset --hard`、`clean -fd` 等正则，对齐 AgentCore 意图）；cwd 锁定为会话工作区。
- 二期：repo 写锁、create_pr（需要远端凭证面，涉及 PRD-05 权限语义，与用户确认后再开）。

## 3. `package_install`（蓝本 589 行）

**AgentCore 行为**：JS（npm/pnpm/yarn）与 Python（pip/uv/poetry）统一纪律；registry 钉死官方源 + CN 镜像白名单，**CLI 覆写 registry 的参数一律拒绝**（`:26-89` 的黑名单正则）；lockfile 感知。

**Magic 复刻（二期初）**：同款 registry 白名单 + 参数黑名单；先 pnpm/npm/pip 三驱动；poetry/uv 随后。

## 4. `code_search`（蓝本 255 行 + 索引引擎）

**AgentCore 行为**：tree-sitter 符号级索引（函数/类/方法）+ BM25 排序（`workspace/indexing/bm25`），`IndexMaintainer` 增量维护；与 grep 互补（grep 精确正则、code_search 概念定位）。

**Magic 复刻（二期）**：依赖一个工作区符号索引引擎——先做「定义行正则预索引」（function/class/method 声明行）+ 简单评分达到可用，tree-sitter 完整复刻单独立项。

## 5. `code_diagnostics` / `write_diagnostics`（蓝本 259 + 143 行）

**AgentCore 行为**：TS/JS 语言服务内环诊断（landed/named 路径的 diagnostics 拉取 + markdown 呈现）。

**Magic 复刻（二期）**：DSH 有 `packages/lsp`，优先接 DSH 语言服务而非自建；无 LSP 的环境回退 tsc --noEmit 抽查。
