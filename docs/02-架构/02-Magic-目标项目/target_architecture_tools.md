# Magic 目标架构设计工具助手

## 用途

本工具助手配合 `target_architecture_prompt.md` 使用。它服务于 Magic 空项目阶段的产品约束提取、目标对象建模、目标架构与首版拆分，不是 Magic 源码扫描器。

## 工具能力

| 能力 | 用途 | 规则 |
|---|---|---|
| 产品文档定向读取 | 读取两份入口文档并提取不变量、首版范围、待裁定和 Go/No-Go | 默认只读两份；补充文档必须记录原因 |
| 产品对象建模 | 建立工程、工作区、任务、Agent、成员、PM、运行、事实和产物关系 | 不把底座对象直接映射成产品对象 |
| 生命周期建模 | 生成任务/运行/会话/成员/审批/副作用状态机 | 每个转移要有触发者、审计和恢复策略 |
| 目标架构生成 | 形成目标模块、数据模型、API、事件、权限和部署方案 | 所有路径标记为目标/待建立 |
| 参考项目对照 | 定向读取 AgentCore 的经验和证据 | 只写参考经验，不写 Magic 现状 |
| 底座核查记录 | 记录 OpenCode 版本、能力、限制和最小复现 | 未实验只能写待技术核查 |
| Mermaid 校验 | 校验目标 DAG、状态图、时序图和数据流图 | 节点标注目标模块或待建立路径 |
| 范围与决策分析 | 生成首版拆分、U-01 至 U-12 矩阵和 Go/No-Go 表 | 不替用户裁定未决产品选择 |

## 推荐顺序

```text
读取两份 Magic 产品入口文档
        ↓
提取产品对象、不变量、首版范围和未决项
        ↓
定向读取 AgentCore 经验或执行 OpenCode 核查
        ↓
建立目标对象、责任、状态和事件契约
        ↓
生成目标模块/API/数据模型/数据流/DAG
        ↓
形成首版拆分、U-01 至 U-12 和 Go/No-Go
        ↓
校验 Mermaid、路径标记和证据等级
```

## 使用纪律

- 不扫描不存在的 Magic 源码，不虚构文件路径、接口、表、事件和测试结果。
- 不把 `D:\Harmess\reference-project\AgentCore` 的路径写成 Magic 实现路径。
- 不把 OpenCode/AgentCore 的 `session`、`agent`、`run`、`task` 直接当作 Magic 产品对象。
- 目标设计、产品不变量、首版建议、待用户裁定、待技术核查和参考经验必须分栏。
- 只读操作可并行；写报告和会改变运行状态的核查串行执行。
- 不读取密钥、token、生产数据和真实用户会话。

## 交付检查

- [ ] Magic 当前无源码的前提已写入报告。
- [ ] 只读取两份必需产品入口文档，补充文档记录了原因。
- [ ] 目标对象、责任、任务账本、运行实例和副作用边界清楚。
- [ ] 任务状态与运行状态分离，责任移交、断连、重试和取消有目标语义。
- [ ] 六条目标数据流、目标 API、事件、数据模型和状态机均可验收。
- [ ] AgentCore 只作为参考经验，OpenCode 能力均有版本/证据边界。
- [ ] U-01 至 U-12 未决项没有被工具擅自裁定。
- [ ] Mermaid 图节点标记为目标模块或待建立路径。
